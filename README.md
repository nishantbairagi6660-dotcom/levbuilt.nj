## 5. Deployment Guide (Beginner-Friendly)

### Option A: Deploy to Vercel (Recommended — 2 Minutes)
1. Go to [vercel.com](https://vercel.com) and sign in (or sign up with GitHub).
2. Click **Add New...** → **Project**.
3. Import your GitHub repository or drag and drop this folder into the Vercel dashboard.
4. Vercel automatically detects the project using the included `vercel.json` and deploys it with a free SSL certificate.

### Option B: Deploy to Netlify
1. Go to [netlify.com](https://netlify.com).
2. Drag and drop this folder onto the **Sites** page.
3. Your site goes live instantly with an HTTPS link.

### Option C: Developer Mode with Vite (Optional)
If you have Node.js installed and wish to run the Vite dev server:
```bash
npm install
npm run dev
```
For production build:
```bash
npm run build
```
